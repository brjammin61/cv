# Logs Directory

This directory stores log files generated by The Oracle system.

## Log Files

- **oracle_dashboard.log**: Main dashboard application logs
- **kalshi_connector.log**: Kalshi API interaction logs
- **polymarket_connector.log**: Polymarket API interaction logs
- **trade_execution.log**: Trade execution records (if enabled)
- **error.log**: Critical errors and exceptions

## Log Levels

The system uses Python's logging module with these levels:

- **DEBUG**: Detailed diagnostic information
- **INFO**: General informational messages
- **WARNING**: Warning messages (non-critical issues)
- **ERROR**: Error messages (failures)
- **CRITICAL**: Critical failures (system shutdown)

## Configuration

To change log level, edit the logging configuration in `oracle_dashboard.py`:

```python
logging.basicConfig(
    level=logging.INFO,  # Change to DEBUG for more detail
    format='%(asctime)s - %(name)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('logs/oracle_dashboard.log'),
        logging.StreamHandler()
    ]
)
```

## Log Rotation

For production use, implement log rotation to prevent files from growing too large:

```python
from logging.handlers import RotatingFileHandler

handler = RotatingFileHandler(
    'logs/oracle_dashboard.log',
    maxBytes=10*1024*1024,  # 10 MB
    backupCount=5
)
```

## Monitoring

Important events to monitor in logs:

- API connection failures
- Signal generation events
- Trade executions (if enabled)
- Errors and exceptions
- Performance metrics

## Notes

- This directory is gitignored to protect sensitive information
- Review logs regularly for issues
- Archive old logs periodically
- Sensitive data (API keys) should NEVER appear in logs
